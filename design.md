# GUIOFF — Design
- Fundo preto puro (#000), superfícies #0a0a0a / #111, bordas brancas 8–10%.
- Acento vermelho #E11D2E (hover #FF2D3F), brilho radial vermelho no rodapé e hero.
- Branco #F5F5F5 para títulos, cinza #8a8a8a para corpo.
- Tipografia: Rubik 300/400/500 (display leve, tracking apertado) + IBM Plex Mono para números.
- Arte isométrica wireframe (cubos em traço fino, gradiente vermelho) com animação de desenho do traço.
- Muito espaço negativo, botões pill com contorno, inputs com sublinhado, paginação numerada 01 02 03.
- Motion: revelação escalonada no carregamento (motion/react), transições suaves 200–400ms.
